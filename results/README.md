# Results

| Path | What it is |
|---|---|
| `tables/` | Generated by `analysis/make_figures.py`: `model_profile.csv` (accuracy, unanimity, unparsed rate, held-out and shuffled accuracy, content-vs-slot shares), `identification.csv` (top-1 identification vs k for every setting), `same_wrong_share_3k.csv` (pairwise matrix), `summary_tables.md` (the same as markdown) |
| `logs/` | Console output of each analysis script, named after the script that produced it (see `analysis/README.md`). The number in a name is the number of models in that snapshot: `_23` and `_26` are 23 and 26 models (Nov 9), and `_27` is 27 models (Nov 11) |
| `pairs/` | Pairwise metrics per model pair: same-wrong `share`, position-bias `null`, `excess` = share − null, co-error `co`, accuracy controls, and the accuracy-controlled residual `res`. `early_*` files come from the 12–17 model snapshots |

The logs record the snapshot each analysis was run on, and the model count is printed at the top of each. Re-running a script on the current `fingerprints/` will include more models, so its numbers can change slightly.
